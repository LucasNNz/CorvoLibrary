CORVO LIBRARY — PACOTE DEFINITIVO VERCEL + TURSO + R2

1. Leia DEPLOY_VERCEL_DEFINITIVO.md.
2. Crie um banco Turso VAZIO.
3. Crie .env.local a partir de .env.example e preencha Turso + o MESMO bucket R2.
4. Execute: npm ci
5. Execute uma única vez: npm run db:migrate:vercel
6. Execute: npm run db:verify:vercel
7. Cadastre as mesmas variáveis no projeto Vercel e publique.

O dump integral do Sites está em migration/full-backup/database.sql.
Nenhum arquivo físico do R2 está neste ZIP. O app acessa os objetos existentes pelas mesmas r2_keys.
Não use as rotas antigas de migração pelo navegador; elas foram desativadas.
