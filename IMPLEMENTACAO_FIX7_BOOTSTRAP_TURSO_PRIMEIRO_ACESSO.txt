CORVO LIBRARY V61.9 FIX7 — BOOTSTRAP TURSO ANTES DO PRIMEIRO LOGIN
=================================================================

PROBLEMA OBSERVADO
------------------
No primeiro acesso a UI exibia "Criar login" mesmo quando o projeto Vercel ainda
não tinha um banco Turso conectado. Ao salvar, o backend tentava criar a tabela
settings e falhava com:

  VERCEL_ENV_REQUIRED:TURSO_DATABASE_URL

A mensagem era tecnicamente correta, mas o fluxo de UX estava errado: um login
persistente e compartilhado entre PCs só pode ser gravado depois que existe um
banco remoto persistente.

CORRECAO
--------
1. O primeiro acesso agora possui uma etapa 0 explícita de DATABASE BOOTSTRAP.
2. /api/auth/status verifica TURSO_DATABASE_URL e TURSO_AUTH_TOKEN antes de ler o DB.
3. Se o recurso não estiver conectado, a UI NÃO mostra nome/senha.
4. A UI mostra "Conectar banco da Library" com acesso à integração Turso da Vercel.
5. A integração Vercel é o caminho recomendado porque injeta as credenciais do
   recurso no deployment; o usuário não precisa editar .env, TXT ou código.
6. Existe "Já conectei — verificar novamente" para refazer o probe.
7. Se as variáveis existirem mas a conexão falhar, a UI mostra estado de
   DATABASE_CONNECTION_FAILED, em vez de expor erro bruto de environment.
8. /api/auth/setup e /api/auth/login também falham de forma controlada com
   DATABASE_BOOTSTRAP_REQUIRED / DATABASE_CONNECTION_FAILED.
9. Só depois do banco responder o formulário simples de nome + senha é exibido.

REGRA ESTRUTURAL
----------------
Não foi criado fallback em SQLite local/arquivo temporário porque Vercel Functions
não fornecem disco persistente compartilhado entre máquinas/deployments. Isso
quebraria o requisito de abrir a mesma Library em qualquer PC.

O bootstrap mínimo inevitável é conectar UM banco remoto ao projeto. Depois disso:
- login fica no Turso;
- Cloudflare/R2/D1 ficam nas settings persistentes da própria Library;
- qualquer PC usa o mesmo estado.

VALIDACAO
---------
- 145/145 regressions PASS.
- Regressões novas cobrem a ordem bootstrap -> login.
- O erro bruto VERCEL_ENV_REQUIRED:TURSO_DATABASE_URL não é mais mostrado no
  formulário de criação de login.
